Class PathTree<Tree>

Easily create a tree of valid paths. Use PathTree.sanitizePaths in your router sanitizer to verify paths.

Note that a path tree can never have allowBare: false and no children (children: {}) in the same path. Doing so will throw an error in this class's constructor.

Example

import {SpaRouter, PathTree} from 'spa-router-vir';

const myPathTree = new PathTree({
    allowBare: true,
    children: {
        'path-a': {},
        'path-b': {},
    },
});

export const myRouter = new SpaRouter({
    sanitizeRoute(rawRoute) {
        return {
            paths: myPathTree.sanitizePaths(rawRoute.paths),
            hash: undefined,
            search: undefined,
        };
    },
});
